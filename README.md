# 🔊 Text-to-Voice

A clean and responsive **text-to-speech web app** built using **HTML, CSS, and JavaScript**.

## 🚀 Demo

👉 [Try it out here](https://dineshkumar9228.github.io/Text-to-Voice/)

## 📋 Features

- 🗣️ Convert typed text into speech using your browser  
- 🎨 Minimalist and responsive UI  
- 🔔 Emoji speaker icon in heading  
- ⚡ Fully client-side (no backend required)  

## 🛠️ Technologies Used

- **HTML5**  
- **CSS3**  
- **JavaScript (Web Speech API)**  

## 📂 How to Run Locally

```bash
# Clone the repository
git clone https://github.com/Dineshkumar9228/Text-to-Voice.git

# Navigate into the project folder
cd Text-to-Voice

# Open the app in your browser
open index.html
